# Data policy

The default demo uses synthetic camera frames generated by
`vision_demo/synthetic_scene.py`. The target position, distractors, and image
size are deterministic, so the result can be reproduced without a camera or
private dataset.

Real images or camera recordings can be added later under this directory only
when their source, license, and capture conditions are documented. Synthetic
results must not be described as measurements from a physical camera.
