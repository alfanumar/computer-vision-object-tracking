# Computer Vision Object Tracking — Personal Validation Project

This project is a reproducible baseline for a robot camera pipeline:

```text
synthetic camera frame -> HSV mask -> contour detection -> target geometry
                                                   |
                                                   v
                                  bounded visual-control command
```

The detector identifies an orange target with classical OpenCV processing. A
small proportional controller converts horizontal image error into an angular
command and target area into a forward-speed command. When the target is not
detected, the command is zero so the system fails safely.

This is a simulation and computer-vision validation project. It does not claim
machine-learning experience, physical-camera validation, or autonomous robot
deployment. The synthetic dataset is generated by the repository and is
clearly reported in `results/summary.json`.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt

python3 -m vision_demo.run_demo --output-dir results
python3 -m pytest -q
```

The demo writes:

- `results/vision_tracking_demo.mp4` — annotated video;
- `results/tracking_log.csv` — per-frame detection and command log;
- `results/summary.json` — detection-rate and pixel-error summary.

## What this demonstrates

- Python and NumPy/OpenCV image processing;
- HSV segmentation, morphology, contours, bounding boxes, and centroids;
- a bounded proportional controller using image measurements;
- deterministic synthetic-data generation;
- logging, basic evaluation, and automated tests.
